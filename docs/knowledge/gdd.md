## 1. Pitch
เดินป่าจริงในอุทยานไทย ในโลก pixel art ที่อบอุ่น
เตรียมเป้ เช็กอากาศ ออกเดิน บริหารแรงและน้ำ ถ่ายภาพทะเลหมอก เก็บตราประทับ แล้วกลับมาแต่งแคมป์ของตัวเอง

**Pillars (ใช้ตัดสินใจเวลาออกแบบขัดกัน)**
1. **Journey over Destination:** ระหว่างทางต้องมีอะไรให้ทำเสมอ
2. **Cozy Challenge:** ท้าทายแต่ไม่ลงโทษหนัก ถ้าล้มเหลวให้กลับแคมป์ ไม่เสียของ
3. **Real Thailand:** สถานที่จริงต้องจำได้ และข้อมูลจริงต้องถูกต้อง
4. **Leave No Trace:** สะสมด้วยการถ่ายภาพและบันทึก ไม่ใช่เก็บจากธรรมชาติ

## 2. Core Loop

### Micro loop (ทุก 30 วินาที – 2 นาที ระหว่างเดิน)
เดิน → เจอสิ่งน่าสนใจ (ของ, จุดชมวิว, สัตว์, เหตุการณ์) → ตัดสินใจ (หยุดพัก / กิน / ถ่ายภาพ / เดินต่อ) → ค่าสถานะเปลี่ยน

### Session loop (1 เส้นทาง ประมาณ 10–20 นาทีจริง)
```
แคมป์: เลือกของใส่เป้ (ข้อจำกัดน้ำหนัก)
  → เลือกเส้นทาง (ดูพยากรณ์อากาศ + ระดับความยาก)
  → เดินป่า (จุดเริ่มต้น → จุดพัก → จุดชมวิว → ปลายทาง)
  → สรุปผล: ตราประทับ, EXP, ของที่ได้, ภาพถ่าย
  → กลับแคมป์
```

### Meta loop (หลายวัน)
EXP → Level → Skill point → เส้นทางยากขึ้น → อุทยานใหม่ → Passport ครบภูมิภาค → Medal / Title

## 3. ระบบ Phase 1 (Core Prototype): รายละเอียดและตัวเลขเริ่มต้น

### 3.1 การเคลื่อนที่
- Top-down 3/4, ขนาด tile 16×16 px, render scale ×3
- เดิน 8 ทิศ (WASD / ลูกศร), วิ่งกด Shift (กิน Stamina ×3)
- ความเร็ว: เดิน 60 px/วิ, วิ่ง 105 px/วิ
- ภูมิประเทศมีผลกับความเร็ว: ทางเดิน ×1.0, หญ้า ×0.85, ทางชัน ×0.6, ทางลื่น (ฝนตก) ×0.75
- น้ำหนักเป้เกินขีดจำกัด → ความเร็ว ×0.7

### 3.2 ค่าสถานะ (0–100)
| ค่า | ลดลงเมื่อ | ฟื้นด้วย | เมื่อเหลือ 0 |
|---|---|---|---|
| Stamina | เดิน 1/วิ, วิ่ง 3/วิ, ทางชัน ×2 | หยุดนิ่ง +4/วิ, นั่งพักที่จุดพัก +10/วิ | เดินได้แค่ช้า (×0.4) |
| Hunger | -0.25/วิ | อาหาร | Stamina ฟื้นช้าลงครึ่งหนึ่ง |
| Thirst | -0.4/วิ (×1.5 ตอนร้อน) | น้ำ, เติมน้ำที่ลำธาร | Stamina สูงสุดลดเหลือ 50 |
| Temperature | ขึ้นกับเวลาและอากาศ | กองไฟ, เสื้อกันหนาว | (Phase 2) |

ตัวเลขทั้งหมดเป็นค่าเริ่มต้น ปรับใน CONFIG

**ล้มเหลว:** ถ้า Hunger และ Thirst เป็น 0 พร้อมกันนาน 10 วินาที → "เจ้าหน้าที่อุทยานพากลับแคมป์" ไม่เสียของ แต่ไม่ได้ตราประทับ

### 3.3 เวลาและแสง
- 1 วันในเกม = 8 นาทีจริง
- ช่วงเวลา: รุ่งเช้า (ทะเลหมอก) → กลางวัน → เย็น (แสงส้ม) → กลางคืน (มืด มองเห็นรอบตัวรัศมีจำกัด)
- เริ่มเดินตอน 06:00 ในเกม

### 3.4 สภาพอากาศ (Phase 1: แบบง่าย)
- แจ่มใส / หมอก / ฝนปรอย
- หมอก: ระยะมองเห็นลดลง แต่จุดชมวิวช่วงเช้าจะได้ภาพ "ทะเลหมอก" (หายาก)
- ฝน: ทางลื่น และ Thirst ลดช้าลง

### 3.5 ของในเป้ (Inventory พื้นฐาน)
- 12 ช่อง, น้ำหนักรวมสูงสุด 6 กก. (v0.2: ถ้าเกินจะเดินช้าลง ×0.7 และใช้แรง ×1.3)
- ก่อนออกเดินมีหน้าจอ "จัดเป้" ให้เลือกของ: ขวดน้ำ, ข้าวเหนียว, ถั่วรวม, เสื้อกันหนาว, เสื้อกันฝน, ไฟฉาย, ชุดชงกาแฟ
- Temperature (v0.2): อุณหภูมิในเกม (ค่าสมมติ) ขึ้นกับเวลา โซน และอากาศ ร่างกายรู้สึก = อากาศ + เสื้อกันหนาว 10°C + เดิน 3°C − เปียกฝน 4°C ถ้าต่ำกว่า 14°C ค่า "อุ่น" จะลด ถ้าสูงกว่า 26°C จะกระหายน้ำเร็วขึ้น
- ของเริ่มต้น: ขวดน้ำ ×2, ข้าวเหนียวหมูปิ้ง ×2, แผนที่
- ของที่หาได้ระหว่างทาง: ขยะที่นักท่องเที่ยวทิ้งไว้ (เก็บแล้วได้ Honor), ของที่นักเดินทางทำหล่น, ใบไม้ร่วง/ก้อนหิน (ของสะสมที่เก็บได้) ส่วนพืชหายากและสัตว์ → **ถ่ายภาพเท่านั้น**

### 3.6 จุดสนใจ (Points of Interest)
| ประเภท | การโต้ตอบ (กด E) |
|---|---|
| จุดเริ่มต้น / ป้าย | อ่านข้อมูลเส้นทาง |
| จุดพัก (ม้านั่ง) | นั่งพัก Stamina ฟื้นเร็ว |
| ลำธาร | เติมน้ำ |
| จุดชมวิว | ถ่ายภาพ บันทึกลง Album |
| พืช / สัตว์ | ถ่ายภาพ บันทึกลง Field Guide |
| ปลายทาง | รับตราประทับ จบด่าน |
| จุดลับ | อยู่นอกทางหลัก ได้ EXP โบนัส |

### 3.7 Navigation
- มินิแมพมุมจอ แสดงตำแหน่ง ทางเดิน และ POI ที่ค้นพบแล้ว
- เข็มทิศชี้ไปปลายทาง
- ป้ายบอกทางในฉาก

### 3.8 ด่านแรก: กิ่วแม่ปาน (ย่อส่วน)
อิงจาก 04-parks-data.md, Beginner, ทางวน
```
[ลานจอด/จุดเริ่ม] → ป่าดิบเขา (มอส, เฟิร์น) → [จุดพัก 1] → ลำธาร
  → ทุ่งหญ้าบนสันเขา → [จุดชมวิว: ผาหน้าหัวช้าง] → กุหลาบพันปี
  → [จุดลับ: มุมทะเลหมอก] → [ปลายทาง: ป้ายเส้นทาง]
```
ไกด์ท้องถิ่น (NPC) ยืนรอที่จุดเริ่ม อธิบายกติกา Leave No Trace (เป็น tutorial)

## 4. ระบบ Phase 2 (Camping & Progression): สรุป
> สถานะ: ทำแล้วใน v0.3–v0.4 (รายละเอียดจริงอยู่ใน progress.md) ยกเว้นการหมุนของและ buff แบบมีเวลา · Skill Tree 8 ทักษะ × 3 ระดับ ได้ 1 แต้มต่อเลเวล
- **แคมป์:** grid 20×15 tile วางของ snap-to-grid, หมุนได้ 4 ทิศ, เริ่มด้วยเต็นท์ + กองไฟ
- **ทำสวน:** แปลง 1 tile ปลูก → รดน้ำวันละครั้ง → โต 3 ระยะ → เก็บเกี่ยว พืชมีฤดูกาล (ร้อน/ฝน/หนาว)
- **ทำอาหาร:** สูตร = วัตถุดิบ + ที่ทำอาหาร ให้ buff ระหว่างเดิน
- **Level:** EXP ที่ต้องใช้ = 100 × level^1.5, ได้ 1 skill point ต่อ level
- **Quest:** กระดานภารกิจ, Daily 3 เควส, เควส tutorial จาก NPC ไกด์
- **Save:** state ทั้งหมดเป็น JSON → localStorage
