# 06 · MULTIPLAYER & SOCIAL

> เริ่มพัฒนาใน Phase 3 แต่ Phase 1–2 ต้องออกแบบโครงสร้างข้อมูลให้รองรับไว้ก่อน
> (แยก game state ออกจาก rendering และให้ทุก action ส่งผ่าน function กลางที่ต่อ server ได้ภายหลัง)

## Co-op
- สร้างปาร์ตี้กับเพื่อน
- เดินป่าและตั้งแคมป์ร่วมกัน
- ช่วยเหลือกันระหว่างทาง
- ทำภารกิจเป็นทีม
- ถ่ายภาพร่วมกัน
- แลกเปลี่ยนไอเทม
- เยี่ยมแคมป์ของเพื่อน (Visitor System)
- ระบบ Party และแสดงสถานะเพื่อน

## Central Hub: ลานกว้างกลางชุมชน
พื้นที่ส่วนกลางที่ผู้เล่นทุกคนมาพบกัน ภายในมี:
- ร้านอุปกรณ์เดินป่า
- ร้านเต็นท์และ Camping Gear
- ร้านเสื้อผ้า
- ร้านอาหาร
- ร้านกาแฟ
- ร้านเมล็ดพันธุ์
- ร้านเฟอร์นิเจอร์
- ร้านของตกแต่งสวน
- ร้านแลกเปลี่ยนไอเทม
- ศูนย์ข้อมูลอุทยาน
- กระดานภารกิจ
- Community Board (กระดานข่าวชุมชน)
- NPC
- จุดจัดกิจกรรม
- จุดรวมกลุ่มก่อนออกเดินทาง

## เศรษฐกิจระหว่างผู้เล่น
- ตลาดกลางสำหรับซื้อขายไอเทมระหว่างผู้เล่น
- Trading System

## Guild
- Guild System: ตั้งชมรมนักเดินป่า
- Guild Ranking: จัดอันดับชมรม
- Camping Contest: ประกวดการตกแต่งแคมป์

## ข้อกำหนดทางเทคนิค
- Server Authority: server เป็นผู้ตัดสินผลทุกอย่าง (ไอเทม เงิน EXP ตำแหน่ง)
- Data Persistence: บันทึกความคืบหน้าของผู้เล่น
- การป้องกันการโกง: ตรวจสอบ action ฝั่ง server, rate limit การซื้อขาย และ validate ระยะทางที่เดิน
