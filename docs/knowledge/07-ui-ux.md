# 07 · UI / UX

## แนวทาง
- ทันสมัย สะอาดตา และใช้งานง่าย
- สไตล์ Pixel Art ผสม Modern Game UI
- รองรับภาษาไทยและอังกฤษ (เลือกฟอนต์ pixel ที่อ่านภาษาไทยได้ หรือใช้ฟอนต์ไทยที่เข้ากับ pixel art)
- HUD ระหว่างเดินป่าต้องเห็นค่าสถานะสำคัญได้ทันที: Stamina, Hunger, Thirst, Temperature, Weight, เวลา, สภาพอากาศ
