# 02 · CORE GAMEPLAY

## A. CHARACTER CREATION
ผู้เล่นสร้างตัวละครก่อนเริ่มเล่น และปรับแต่งได้อิสระ
- เพศหรือรูปลักษณ์
- ทรงผมและสีผม
- สีผิว
- ใบหน้า
- ชุดเดินป่า
- รองเท้า
- กระเป๋าเป้
- หมวก
- เครื่องประดับ
- ชื่อตัวละคร

ชุดมีทั้งแบบธรรมดาและแบบพิเศษที่ปลดล็อกจากการเล่น
มีระบบ Outfit Preset สำหรับบันทึกชุดได้หลายแบบ

## B. HIKING MECHANICS (หัวใจของการเล่น)

### ค่าสถานะ
| ระบบ | คำอธิบาย |
|---|---|
| Stamina | พลังงานในการเดิน |
| Hunger | ความหิว |
| Thirst | ความกระหาย |
| Temperature | อุณหภูมิร่างกาย |
| Backpack Weight | น้ำหนักสัมภาระ |
| Equipment Durability | ความทนทานของอุปกรณ์ |
| Weather | สภาพอากาศ |
| Day & Night Cycle | กลางวันและกลางคืน |

### เหตุการณ์ระหว่างเดินป่า
- ฝนตก
- หมอกลง
- อุณหภูมิลดลง
- ทางเดินลื่น
- พบสัตว์ป่า
- พบพืชหายาก
- พบจุดชมวิวลับ
- พบถ้ำ
- พบแหล่งน้ำ
- พบสิ่งของที่นักเดินทางคนก่อนทำตกไว้

### Navigation
- แผนที่
- เข็มทิศ
- ป้ายบอกทาง
- GPS ในเกม
- ทำเครื่องหมายบนแผนที่

**กฎสำคัญ:** แต่ละด่านต้องเล่นแตกต่างกัน ไม่ใช่แค่เดินจากจุด A ไป B

### ระบบเสริมที่เกี่ยวข้อง
- Mountaineering Gear: อุปกรณ์เดินป่าหลายระดับ
- Weather Forecast: ดูพยากรณ์อากาศก่อนออกเดินทาง
- Dynamic Weather: สภาพอากาศเปลี่ยนแปลงระหว่างเดิน
- Pet Companion: สัตว์เลี้ยงเป็นเพื่อนร่วมทาง โดยไม่รบกวนสัตว์ป่า

## C. CAMPING & HOME BUILDING
ผู้เล่นมีพื้นที่ส่วนตัวที่พัฒนาและตกแต่งได้

### สิ่งที่สร้างได้
เต็นท์หลายแบบ, บ้านไม้, กระท่อม, บ้านพักกลางป่า, เปลนอน, กองไฟ, โต๊ะทำอาหาร, ห้องเก็บอุปกรณ์, ห้องนอน, ห้องครัว, ห้องเก็บถ้วยรางวัล

### การตกแต่ง
- วางเฟอร์นิเจอร์อิสระ
- เปลี่ยนพื้นและทางเดิน
- วางต้นไม้และดอกไม้
- สวนผัก สวนดอกไม้
- หิน น้ำพุ บ่อน้ำ
- ไฟประดับ
- วางของสะสมจากการเดินป่า

### Gardening
ปลูกผัก ผลไม้ ดอกไม้ → รดน้ำ → เก็บเกี่ยว → ขายหรือนำไปทำอาหาร
มีฤดูกาลที่ส่งผลต่อการปลูกพืชและการตกแต่ง (Seasonal Environment)

## D. COOKING & SURVIVAL CRAFTING
- ทำอาหาร ชงกาแฟ ทำเครื่องดื่ม
- ทำอาหารสำหรับพกไปเดินป่า
- คราฟต์อุปกรณ์ตั้งแคมป์
- ซ่อมอุปกรณ์
- สร้างเฟอร์นิเจอร์และของตกแต่ง

อาหารแต่ละประเภทให้โบนัสต่างกัน เช่น เพิ่ม Stamina ฟื้นพลังงาน หรือช่วยการเดินทาง

---

## E. PHOTOGRAPHY
มีโหมดถ่ายภาพ ใช้ถ่าย:
ภูเขา, น้ำตก, พระอาทิตย์ขึ้น, ทะเลหมอก, สัตว์ป่า, ดอกไม้, จุดชมวิว, เพื่อนร่วมทาง

- ภาพบันทึกลงสมุดสะสมได้ (Photo Album)
- ใช้ส่งเข้ากิจกรรมถ่ายภาพประจำสัปดาห์ได้ (Photo Contest)

## F. GAMEPLAY LOOP (ร่างเบื้องต้น ให้ GDD ขยายต่อ)
```
แคมป์ (เตรียมตัว ทำอาหาร เช็กพยากรณ์อากาศ)
   → Hub (รับเควส ซื้ออุปกรณ์ รวมปาร์ตี้)
   → เดินป่าในอุทยาน (บริหารค่าสถานะ เจอเหตุการณ์ สำรวจ ถ่ายภาพ เก็บของ)
   → พิชิตเส้นทาง (ตราประทับ EXP รางวัล)
   → กลับแคมป์ (ตกแต่ง ปลูกผัก จัดแสดงของสะสม)
   → วนกลับไปเริ่มรอบใหม่
```
